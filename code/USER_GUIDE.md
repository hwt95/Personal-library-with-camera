# 个人藏书管理 1.2

作者：Gimi.H with Chatgpt model

这是 Windows x64 本地桌面便携程序。解压整个压缩包，双击 `PersonalLibrary.exe`。
程序已包含 Python、Qt、OpenCV、条码识别库、本地方向模型、CPU 推理库及中文字体，无需安装这些组件、配置环境变量或启动数据库服务器。
请保留 exe 旁的 `_internal` 文件夹。目标为 Windows 10/11 64 位；仍需要正常的 Windows 系统和摄像头驱动。

中文使用“霞鹜文楷 / LXGW WenKai”v1.530 Regular；英文和数字使用 Tinos Regular，外观接近 Times New Roman。阿拉伯语使用内置 Noto Sans Arabic 的 Regular 字重，并启用从右向左布局。全界面使用常规字重，发行包仅包含这三个必要字体文件，不含旧字体、Bold/Light/Italic 或整套字体压缩包。字体离线加载，无需安装系统字体，均采用允许商用及随软件分发的 SIL Open Font License 1.1；完整版权与许可保存在 `licenses/font`，原始来源和校验值也随包提供。

## 语言、许可与项目入口

首次启动仅在简体中文系统环境默认使用简体中文，其余环境（含繁体中文）默认英文。设置中可手动选择简体中文、英语、法语、西班牙语、俄语、阿拉伯语；切换立即生效、保留草稿并记住选择。界面翻译不改写书目和地点等用户数据。

设置页的“软件许可与第三方协议”可搜索并查看随包提供的完整文本。原创代码采用 PolyForm Noncommercial 1.0.0，属于源码可见、用途受限许可，并非 OSI 开源许可；超出许可允许用途的商业使用需单独书面授权。Qt/PySide/Shiboken 等继续保留各自许可与替换权利。数据源权利独立，见 DATA_SOURCES.md。设置另提供项目主页、GitHub Issues 与对应源码说明入口。

第三方源码改为在许可窗口点击“第三方源码下载”后通过外部链接获取，页面列明精确版本及 SHA-256。日常使用无需下载源码，程序目录不再安装 `sources` 文件夹。许可证原文仍随包提供，换库与重新分发说明见 `SOURCE_CODE.md`。

## 第一次使用

1. 选择“新建数据库”，将文件保存在自己的文档、移动硬盘或其他便于备份的位置。不要把正式藏书放入开发项目的 build 目录。
2. 输入 ISBN 后点击“查询资料”，或直接填写书名与本册出版年份。
3. 核对作者、译者、出版社及所选体系的分类号。网络年份仅供参考，本册年份必须自行填写。
4. 在“设置 → 预设存放地点”中添加常用地点，录入时点击“勾选预设地点”选取存放位置。
5. 点击“确认保存”。没有 ISBN、分类或封面的旧书同样可以登记，缺分类时生成明确标注的临时编号。

## 图书、杂志与阅读状态

录入页先选“图书”或“杂志 / 期刊”。杂志记录刊名、年度和期数，不要求作者、分类号或简介。不同年度或期次作为独立记录，以保存各期封面；同一期可继续登记副本。

摄像头读取 977 开头的 EAN-13 后恢复 ISSN；识别到 EAN-2 两位附加码时填入期数供核对。主码中的价格/变体位不当作期数；EAN-5 五位附加码含义不统一，保留原码并由用户核对期数。普通条码不能可靠给出完整年度，需按封面填写。ISBN 后的价格附加码不会变成杂志期数。

每册可选择“未阅读、阅读中、已阅读”，新记录默认未阅读，编辑已有记录时保留原状态。列表与组合检索可按类型、阅读状态筛选；点击右侧封面可放大并缩放查看。

## 预设存放地点

在设置页输入地点名称后点击“添加地点”，例如“书房 A 架”“客厅书柜上层”。选中列表中的地点后，可修改名称或删除预设；所有改动自动保存。地点名称不能重复或为空。

录入页的“勾选预设地点”菜单会显示这些地点，每本实体书选择一个地点，也可以选择“不设置地点”或直接在输入框手填。编辑旧记录时保留原来的地点，即使该名称已不在预设列表中；改名或删除预设不会改写已保存书籍的位置。重置草稿后地点清空，以免下一册误用上一册位置。

预设列表保存在程序旁的 settings.json 中，重新启动和切换藏书数据库后仍可使用。每册实际选择的地点随藏书存入 SQLite，完整数据库备份会保留这些位置；如需一同搬移预设列表，可同时保留个人设置文件。

## 四个页面

- **录入**：手工/扫码录入、照片封面、编辑已有记录。摄像头按钮开启预览；默认自动选择第一个可用设备。
- **藏书列表**：分类号前缀、作者、出版社、年份范围、位置、待分类、缺封面及有副本筛选。双击记录进入编辑。选中记录可查看封面与简介。
- **组合检索**：快速搜索包含书籍简介；高级检索可单独填写“简介包含”，与其他字段组合 AND 或 OR。结果表显示简介摘要，优先展示命中词附近的内容，悬停或选中记录可查看完整简介。年份区间作为一个条件；快速搜索与高级条件组合采用 AND，状态勾选也采用 AND。ISBN 与编码可精确匹配，其余文本按包含匹配，分类按前缀匹配。
- **设置**：管理预设存放地点，查看版本与作者，选择来源与摄像头，切换数据库、新建库、备份、另存副本、导入分类字典和重置。

列表默认按分类前缀、书目流水号和副本号排序，数值 `(2)` 排在 `(10)` 前。另有同书目年份从新到旧预设。点击表头切换该列升降序。

## 馆藏与副本

编号按分类分别递增：`TP303-001`、`TP303-002`，另一个分类从 `I247.57-001` 开始。超过 999 自动扩展位数。同书额外副本为 `TP303-001(1)`、`(2)`。删除副本后不复用已分配的后缀。全部副本删除后保留书目及编号计数，方便再次录入时沿用。

同 ISBN 优先复用本地资料；特殊版本可勾选“作为新版本登记”。书目资料与封面由副本共享，每册的年份、位置和备注独立。修改分类号时，整条书目在新分类中取得下一个编号，副本后缀不变，旧编号不再复用。未分类图书使用 PENDING 前缀，杂志使用独立 MAG 序列。

1.1 数据库首次用 1.2 打开时，先在数据库旁 backups 目录生成 pre-1.2 备份，再升级至结构版本 3，既有编号和分类号均保留，旧书目标记为 CLC。1.0 数据库先备份为 pre-1.1，再完成分类内编号和多体系结构升级。备份失败则不升级。升级后的库需使用 1.2；旧程序无法打开新结构，如需回退，请使用升级前备份的副本。

## 自适应分类规则（1.2）

首次启动不要求判断 DDC 和 LCC：自动模式按当前界面语言选择，简体中文为 CLC，其他语言为 DDC。设置中的“图书分类与馆藏编号”可指定 CLC、DDC 或 LCC，也可以保持自动。策略保存在当前数据库，切换数据库时使用该库的策略。每条书目保存自身分类体系，切换语言只改变自动模式下空白新草稿的默认值，不改写既有馆藏或正在编辑的草稿。

DDC 使用十进数字，LCC 使用字母和数字，二者不能直接互换。默认 DDC 是本程序面向个人藏书的选择；已有 LCC 书架标签或需要保持 LCC 编排的用户可手动指定。示例：`TP303-001`、`DDC-005.133-001`、`LCC-QA76.73.P98-001`。不同体系和分类分别计数；未分类分别为 `PENDING-001`、`DDC-PENDING-001`、`LCC-PENDING-001`。编号末尾的顺序号是本程序的馆藏管理编号。

点击“应用分类规则…”会显示影响范围和最多 200 种书目的编号预览；只有确认后才写入数据库：

- **仅用于新录入**（默认）：保留旧书目编号。新草稿使用新默认；未保存草稿保留已选体系。
- **同步已有书目**：对体系不同的图书使用已保存的目标分类号重新分配编号。缺失时标为该体系的待分类，保留旧分类号；不联网批量查询，不猜测 CLC/DDC/LCC 对照。包括已删除全部副本但仍保留的书目，以免后续复用旧体系。杂志不参与。

同步前在数据库旁 backups 中创建完整备份；备份失败不改数据，数据库写入失败回滚。每册旧新编号保存在编号变更记录，可在设置中导出 CSV；副本后缀、封面、阅读状态和存放位置保留。再次切换回旧体系也会领取新的分类内序号，不复用历史编号。恢复到同步前状态可通过“打开现有库”打开备份的副本。

录入时可单独更改“分类体系”，各体系输入值独立保存；已录入书目的体系变更与分类号修改一样，需要确认共享资料和编码变更。列表显示体系和当前分类号，详情还可查看保留的其他体系分类号。分类前缀筛选作用于每条书目当前体系的分类号。

Open Library 返回明确 DDC/LCC 编号时可自动填入；多个不一致候选不会擅自选取。国图只提供其返回的 CLC，Google 主题不视作分类号。缺失值可手填或待分类。字典按体系隔离；设置中的 CSV 导入面向**已应用的当前规则**，切换规则并应用后再导入相应字典。完整 DDC/LCC 类目表不随包附带，导入内容须有相应使用权。

## 书目来源

简体中文界面默认按本地 → 国家图书馆 → Open Library → 已配置的 Google Books 查询；其他界面语言隐藏并跳过国图，使用 Open Library 和 Google Books。国图没有应用层等待截止时间，界面显示等待秒数；可点击取消，关闭实际请求，然后手工填写或选择其他来源。系统、代理或服务器仍可能中断连接。

国图接入仅供测试，不能用于商业用途。来源全称为“中国国家图书馆·中国国家数字图书馆网站”（https://www.nlc.cn/），引用时须保留作者与出处，其他使用须遵守其版权声明并取得所需许可。测试标注不代表已获得数据采集许可。

Google Books 在配置 API Key 后参与查询，按其服务条款使用；本程序不会替用户启用计费。遇到额度或访问错误可使用其他来源。自动查询在首次取得候选或书目后停止；不会保证中文图书覆盖率，也不会将一般主题、DDC 或 LCC 转成中图分类号。

来源缺字段时可手填。查询期间手工修改的字段和拍摄/导入的封面不会被返回结果覆盖。国图多结果先选候选再读取详情，并核对 ISBN；多个分类号由用户选定主分类。

## 封面拍摄

摄像头开启时默认请求自动对焦。录入页和拍摄窗口均提供“自动对焦”开关、“重新对焦”、1–4 倍缩放滑块与“复位”。缩放为中心数字裁切，取景、扫码和拍摄采用同一范围，不需要设备支持光学变焦；放大后的有效像素相应减少。自动对焦取决于摄像头和驱动支持情况，不支持时会显示具体提示，缩放和拍摄仍可使用。

点击“拍摄封面”打开独立窗口，或“导入图片”处理已有照片。保持封面四角都在画面内，尽量避免反光。取景时由本地 DocAligner T8 模型检测四角，拍摄后使用 T8/LCNet、局部再检测与 OpenCV 直线细化，并保留传统 OpenCV 回退。边框显示为细的黑白描边与洋红虚线；按空格拍摄后从拍摄原图重新检测并进行透视裁切和朝向识别。

点击“放大调整四角”打开大窗口。拖动顶点时实时显示原图坐标和局部放大镜；方向键移动 1 像素，Shift+方向键移动 10 像素，应用后重新裁切，取消不改变原四角。左侧也可拖动四角，右侧查看结果；“自动识别边框”可以重新检测原图，并保留已经选择的旋转方向。左右旋转按钮用于手动转正。朝向置信度不足时保持原方向，边框识别失败时保留完整照片供手动调整。Enter 采用封面，Esc 取消。照片不上传，采用后先进入草稿，保存书目时写入数据库。

最终 JPEG 长边不超过 1280 像素。读取 ISBN/ISSN 后停止条码解码，摄像头保持开启进入封面模式；拍摄窗口共用该摄像头。保存或重置草稿后才恢复下一册扫码；同一条码需离开画面约 1.5 秒后才能再次自动触发，也可直接使用“继续录入同书副本”。

## 快捷键

- 录入页 ISBN 尚未查询时 Enter 查询；资料就绪时 Enter 保存。
- Ctrl+Enter 保存；简介内普通 Enter 换行。
- 拍摄窗口中空格只用于拍摄，不会切换自动对焦；对焦使用开关或“重新对焦”按钮。
- Esc 重置当前草稿。输入框内 Backspace 删除文字，非编辑区域 Backspace 重置草稿。
- 弹窗期间主页面快捷键不响应。保存后短时间内重复按键不会重复建册。

## 备份与搬移

书目、最终封面、导入的分类字典均在所选 SQLite 文件内。使用程序内“完整备份”可以在运行期间生成一致副本；手工复制数据库请先正常退出程序。备份不覆盖已有文件，请使用新的文件名。

重置前会显示当前数据库路径和册数，并自动创建同目录 `backups` 文件夹中的时间戳备份；备份失败则取消重置。重置保留分类字典，清空书目、馆藏和编号计数。恢复时用“打开现有库”选择备份，建议先复制一份再打开使用。

同一个数据库同时只允许一个本程序窗口打开。运行时可能有 SQLite 日志与锁文件，正常退出后可只搬移数据库。

来源、可选 Key、摄像头序号与数据库路径保存在程序旁的 `settings.json`。数据库在程序目录下时记录相对路径，可连同文件夹搬移；数据库单独搬移后重新选择即可。只读程序目录会尝试使用 Windows 用户配置目录。Key 不进入数据库、CSV 或发行包；自己填写 Key 后分享程序目录前请移除个人设置文件。

分类 CSV 编码为 UTF-8，列名 `code,name,parent_code,source,edition`。内置 22 个基本大类，细分类号可自由输入；未收录时显示“名称未收录”。CSV 导出当前检索结果，封面仍只保存在完整数据库中。
