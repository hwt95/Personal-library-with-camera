# 个人藏书管理 1.0

作者：Gimi.H with Chatgpt model

这是 Windows x64 本地桌面便携程序。解压整个压缩包，双击 `PersonalLibrary.exe`。
程序已包含 Python、Qt、OpenCV、条码识别库、本地方向模型、CPU 推理库及中文字体，无需安装这些组件、配置环境变量或启动数据库服务器。
请保留 exe 旁的 `_internal` 文件夹。目标为 Windows 10/11 64 位；仍需要正常的 Windows 系统和摄像头驱动。

应用内中英文统一使用 Google Fonts 收录的“霞鹜文楷 TC / LXGW WenKai TC”（楷体风格），包含常规和粗体；生僻字由同样内置的 Noto Sans SC 补充。字体随程序离线加载，无需安装系统字体。两者采用允许商用及随软件分发的 SIL Open Font License 1.1，完整版权与许可保存在 `licenses/font`。字体文件保持原样，来源与校验值也随包提供。

## 第一次使用

1. 选择“新建数据库”，将文件保存在自己的文档、移动硬盘或其他便于备份的位置。建议将藏书数据库保存在程序目录之外。
2. 输入 ISBN 后点击“查询资料”，或直接填写书名与本册出版年份。
3. 核对作者、译者、出版社及中图分类号。网络年份仅供参考，本册年份必须自行填写。
4. 在“设置 → 预设存放地点”中添加常用地点，录入时点击“勾选预设地点”选取存放位置。
5. 点击“确认保存”。没有 ISBN、分类或封面的旧书同样可以登记，缺分类时生成明确标注的临时编号。

## 预设存放地点

在设置页输入地点名称后点击“添加地点”，例如“书房 A 架”“客厅书柜上层”。选中列表中的地点后，可修改名称或删除预设；所有改动自动保存。地点名称不能重复或为空。

录入页的“勾选预设地点”菜单会显示这些地点，每本实体书选择一个地点，也可以选择“不设置地点”或直接在输入框手填。编辑旧记录时保留原来的地点，即使该名称已不在预设列表中；改名或删除预设不会改写已保存书籍的位置。重置草稿后地点清空，以免下一册误用上一册位置。

预设列表保存在程序旁的 settings.json 中，重新启动和切换藏书数据库后仍可使用。每册实际选择的地点随藏书存入 SQLite，完整数据库备份会保留这些位置；如需一同搬移预设列表，可同时保留个人设置文件。

## 四个页面

- **录入**：手工/扫码录入、照片封面、编辑已有记录。摄像头按钮开启预览；默认自动选择第一个可用设备。
- **藏书列表**：分类号前缀、作者、出版社、年份范围、位置、待分类、缺封面及有副本筛选。双击记录进入编辑。选中记录可查看封面与简介。
- **组合检索**：快速搜索包含书籍简介；高级检索可单独填写“简介包含”，与其他字段组合 AND 或 OR。结果表显示简介摘要，优先展示命中词附近的内容，悬停或选中记录可查看完整简介。年份区间作为一个条件；快速搜索与高级条件组合采用 AND，状态勾选也采用 AND。ISBN 与编码可精确匹配，其余文本按包含匹配，分类按前缀匹配。
- **设置**：管理预设存放地点，查看版本与作者，选择来源与摄像头，切换数据库、新建库、备份、另存副本、导入分类字典和重置。

列表默认按分类前缀、书目流水号和副本号排序，数值 `(2)` 排在 `(10)` 前。另有同书目年份从新到旧预设。点击表头切换该列升降序。

## 馆藏与副本

一本新书首次登记为 `TP303-000001`，同书额外副本为 `TP303-000001(1)`、`(2)`。删除副本后不复用已分配的后缀。全部副本删除后保留书目及编号计数，方便再次录入时沿用。

同 ISBN 优先复用本地资料；特殊版本可勾选“作为新版本登记”。书目资料与封面由副本共享，每册的年份、位置和备注独立。修改分类号时，会提示全部副本的编号前缀变更；流水号和副本号保持不变。

## 免费来源

默认按本地 → 国家图书馆 → Open Library → 已配置的 Google Books 查询。国图没有应用层等待截止时间，界面显示等待秒数；可点击取消，关闭实际请求，然后手工填写或选择其他来源。系统、代理或服务器仍可能中断连接。

Google Books 仅在填写免费可用的 API Key 后参与自动查询，程序不会启用计费。遇到额度或访问错误可使用其他来源。自动查询在首次取得候选或书目后停止；不会保证中文图书覆盖率，也不会将一般主题、DDC 或 LCC 转成中图分类号。

来源缺字段时可手填。查询期间手工修改的字段和拍摄/导入的封面不会被返回结果覆盖。国图多结果先选候选再读取详情，并核对 ISBN；多个分类号由用户选定主分类。

## 封面拍摄

摄像头开启时默认请求自动对焦。录入页和拍摄窗口均提供“自动对焦”开关、“重新对焦”、1–4 倍缩放滑块与“复位”。缩放为中心数字裁切，取景、扫码和拍摄采用同一范围，不需要设备支持光学变焦；放大后的有效像素相应减少。自动对焦取决于摄像头和驱动支持情况，不支持时会显示具体提示，缩放和拍摄仍可使用。

点击“拍摄封面”打开独立窗口，或“导入图片”处理已有照片。保持封面四角都在画面内，尽量避免反光。取景时由 OpenCV 在后台自动识别封面边框，并显示绿色四边形；按空格拍摄后从拍摄原图重新检测并进行透视裁切和朝向识别。

左侧拖动四个角可重新裁切，右侧查看结果；“自动识别边框”可以重新检测原图，并保留已经选择的旋转方向。左右旋转按钮用于手动转正。朝向置信度不足时保持原方向，边框识别失败时保留完整照片供手动调整。Enter 采用封面，Esc 取消。照片不上传，采用后先进入草稿，保存书目时写入数据库。

最终 JPEG 长边不超过 1280 像素。拍摄窗口共用摄像头，并暂停主窗口扫码。关闭后恢复；同一条码需离开画面约 1.5 秒后才能再次自动触发，也可直接使用“继续录入同书副本”。

## 快捷键

- 录入页 ISBN 尚未查询时 Enter 查询；资料就绪时 Enter 保存。
- Ctrl+Enter 保存；简介内普通 Enter 换行。
- Esc 重置当前草稿。输入框内 Backspace 删除文字，非编辑区域 Backspace 重置草稿。
- 弹窗期间主页面快捷键不响应。保存后短时间内重复按键不会重复建册。

## 备份与搬移

书目、最终封面、导入的分类字典均在所选 SQLite 文件内。使用程序内“完整备份”可以在运行期间生成一致副本；手工复制数据库请先正常退出程序。备份不覆盖已有文件，请使用新的文件名。

重置前会显示当前数据库路径和册数，并自动创建同目录 `backups` 文件夹中的时间戳备份；备份失败则取消重置。重置保留分类字典，清空书目、馆藏和编号计数。恢复时用“打开现有库”选择备份，建议先复制一份再打开使用。

同一个数据库同时只允许一个本程序窗口打开。运行时可能有 SQLite 日志与锁文件，正常退出后可只搬移数据库。

来源、可选 Key、摄像头序号与数据库路径保存在程序旁的 `settings.json`。数据库在程序目录下时记录相对路径，可连同文件夹搬移；数据库单独搬移后重新选择即可。只读程序目录会尝试使用 Windows 用户配置目录。Key 不进入数据库、CSV 或发行包；自己填写 Key 后分享程序目录前请移除个人设置文件。

分类 CSV 编码为 UTF-8，列名 `code,name,parent_code,source,edition`。内置 22 个基本大类，细分类号可自由输入；未收录时显示“名称未收录”。CSV 导出当前检索结果，封面仍只保存在完整数据库中。

## 自检与适用边界

命令行运行 `PersonalLibrary.exe --self-test 完整路径\report.json` 会使用临时测试库执行离线自检并生成 JSON 与界面截图，不打开摄像头或查询网络。可用 `--db 完整路径\library.sqlite3` 打开指定数据库。

本版为单机单用户工具，不包含账号、同步、批量书目导入、借还管理或版权页 OCR。摄像头对焦、真实封面反光与网络来源可用性需结合实际设备试用。

第三方许可见 `licenses`、`THIRD_PARTY.json` 与 `THIRD_PARTY_NOTICES.txt`。
